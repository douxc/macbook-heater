# macbook-heater
针对 MacBook Pro 及 MacBook Air 铝合金机身在冬季冰冷的触感，通过调动 CPU 负载产生热能以提升机身温度，改善使用时的“冰手”体验。

> **娱乐项目**：本页面纯属好玩，请勿当真。

[开火](https://douxc.github.io/macbook-heater/)

**顺便做点正事**：同样的满载算力可以捐给科研志愿计算——[Science United](https://scienceunited.org/)（自动分配 BOINC 项目）或 [Folding@home](https://foldingathome.org/)（蛋白质折叠）。需另装客户端，与本页面无关。
